# Stipe Docs

Stipe keeps most operator-facing documentation close to the root so the command
surface stays easy to find.

Use these files first:

- [../README.md](../README.md): what Stipe is, what it owns, and the main CLI
  flows
- [../ROADMAP.md](../ROADMAP.md): Stipe-specific backlog and near-term direction
- [plans/README.md](plans/README.md): active planning entrypoint
- [../CHANGELOG.md](../CHANGELOG.md): release history
- [../scripts/claude/README.md](../scripts/claude/README.md): transitional
  Claude-specific fallback helpers

This `docs/` directory is intentionally light. Add repo-local design notes here
only when they need to persist as canonical Stipe documentation rather than
temporary handoffs or workspace-wide guidance.
